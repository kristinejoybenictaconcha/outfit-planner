# Kristine Joy Outfit Planner

A mobile-friendly web app to organize clothes and plan outfits for the week.

Created by: **Kristine Joy B. Concha**
Section: **BSINTE 2A**
School: Nueva Vizcaya State University - Bambang Campus

## Description
The Kristine Joy Outfit Planner helps users create outfits, save them, plan what to wear from Monday to Sunday, get weather-based outfit suggestions, and manage a shopping list. All data is saved in the browser using Local Storage.

## Features
1. Home / Welcome - Overview of the app
2. Create Outfit - Choose top, bottom, shoes, and accessories and save as an outfit
3. My Outfits - View, search, and delete saved outfits
4. Weekly Planner - Assign outfits for Monday to Sunday
5. Weather Suggestions - Get outfit suggestions based on weather (Sunny, Rainy, Cold, Cloudy)
6. Shopping List - Add and manage items to buy
